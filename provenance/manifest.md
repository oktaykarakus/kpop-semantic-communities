## Input restrictions and limits

The staged scripts require source-project data and intermediate artifacts described in the root README. No such input is included. The upstream repository is identified as `EX3exp/Kpop-lyric-datasets`, inspected at commit `a7d141f5431fffb61c52c8ec1e48553975fa6350`; the exact link of that snapshot to the study input and the full historical lineage to 7,891 songs remain unverified.
